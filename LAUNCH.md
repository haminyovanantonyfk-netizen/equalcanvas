# Share EqualCanvas

## LinkedIn launch

I've released EqualCanvas v0.2: a completely free, MIT open-source browser app for exploring and editing diagrams through their connections.

The goal is to make shared .drawio files easier to work with using a keyboard, relationship controls, and a synchronized visual preview.

You can build a flow from a list, organize pages with undo, follow connections, check for loose ends, and export a readable text outline. Diagrams are processed locally, and the app works offline after its first successful load.

No subscriptions, paid feature tiers, accounts, or API keys.

This is an early working release. Automated checks pass, but we still need real screen-reader testing and feedback from blind and low-vision users. I'm sharing the code and inviting contributions, not claiming accessibility is solved.

## Reddit launch

Title: I built EqualCanvas, a free offline .drawio editor focused on navigating connections

I'm the project's creator. EqualCanvas pairs keyboard-operated controls for incoming/outgoing connections with a visual diagram preview. The aim is to help people collaborate on the same .drawio file without depending only on its visual layout.

v0.2 adds page management with undo, list-to-flow creation, searchable quick actions, structural checks, and plain-text export. Files stay in browser memory; download to save. No accounts, API keys, or subscriptions. The code is MIT licensed and the app is completely free.

It is early: complex shapes and rich formatting are simplified, and automated accessibility checks don't replace testing with blind participants or screen readers. I'd appreciate feedback on navigation and any file-preservation problems, using non-private examples.
